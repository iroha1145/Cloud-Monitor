# Animated navigation icons

SVG outlines and short stroke choreography adapted from lucide-animated by
pqoqubbw, inspected 2026-10-18. The local component uses native Web Animations
with one-shot feedback, parent-control events and reduced-motion cancellation;
it does not copy the upstream interaction wrapper.

Primary sources:
- https://lucide-animated.com/llms.txt
- https://lucide-animated.com/icons/llms.txt
- https://github.com/pqoqubbw/icons/tree/main/icons
- https://github.com/pqoqubbw/icons/blob/main/LICENSE

Per-icon documentation and registry sources were inspected at
`https://lucide-animated.com/icons/<name>.md` and
`https://lucide-animated.com/r/<name>.json` for `layout-grid`, `layers`,
`monitor-check`, `wallet`, `history`, `search`, `settings`, `download`,
`refresh-cw`, `x` and `menu`. Monitor's check is replaced by a temporary screen
scan so a device icon does not claim a health status. Translation distances,
rotations and durations are shortened to fit the dashboard's 19px controls.
