# 安卓用量工作台设计

本次原生应用沿用 v0.2.0 网页工作台的信息结构和统计口径。最低支持安卓14（Android 14），面向安卓17构建；不再保留旧安卓版本的布局与平台分支。

## 界面基础

| 含义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#FAFAFB` | `#191B20` |
| 内容卡片 | `#FFFFFF` | `#24262D` |
| 主文字 | `#20242B` | `#F1F3F5` |
| 辅助文字 | `#606775` | `#B0B6C0` |
| 主色 | `#2672C0` | `#8ABCF0` |
| 边框 | `#ECEEF1` | `#323640` |

界面以当前网页的手机版布局为参照，具体依据为 `hub/dashboard/src/styles.css`、`mobile.css` 和 `InsightTrend.tsx`。卡片采用10dp圆角与细边框；分段按钮使用浅灰底、白色选中项，底部导航使用整块浅蓝色选中背景。搜索框、标题、摘要卡和数据行统一到网页的尺寸与间距。弹窗和底部详情面板使用安卓原生组件。

应用图标沿用网页青绿色渐变云朵与浅绿色状态点，自适应图标保留安全区域，并提供单色主题图标。

输入、输出、缓存读取、缓存写入、未分类各有固定颜色，同时显示文字标签与数值。颜色不能独自表达异常或数据分类。金额缺失显示“未提供”，真实零值显示0。

## 页面与交互

- **总览**：今日、本月、累计用量与费用；四格摘要、独立用量组成、模型用量；近7天或30天折线趋势；客户端用量、提供商状态及最近会话。
- **设备**：搜索、在线状态筛选、健康状态、客户端和可展开的诊断信息。
- **模型**：按周期查看各模型用量、费用及缓存占比；搜索和排序；工具与模型分布。
- **额度**：保留上游来源、重置时间、授权失败和缺失额度的区别。
- **历史**：活动分布、按日归档和会话明细；可搜索、筛选及导出当前筛选结果。

手机采用五项底部导航，顺序与网页一致：总览、模型、设备、配额、历史；宽度超过760dp时改为侧边导航，960dp以内的手机短横屏保留底部导航。内容限宽，表格允许横向滑动。系统栏与键盘由原生窗口边距处理，不估算状态栏高度。页面保留各自滚动位置；回到总览后由系统处理返回手势。

趋势卡默认展示30天，右上角可切换7天；同时列出区间词元、区间或已知花费、缓存占比。内嵌图表可切换词元与费用，沿用网页的平滑曲线、浅灰内框和日期标记。曲线只用于展示走势，点按、拖动、前后日期按钮和辅助功能读取的均为每日原始记录。日期按钮打开原生明细面板；没有独立日期滑块或常驻明细卡。费用缺失时不画连续费用线，避免把缺失数据当作零值。刷新可通过下拉或页面按钮触发；顶部提供外观切换和更多菜单。

## 数据约定

详见 [总览接口契约](TM_OVERVIEW_CONTRACT.md)。原生适配保留字段是否实际返回的信息：每日缓存占比只使用有效日期的缓存读取与同日词元总量之和。缺失日期从分子、分母同时剔除，并显示统计天数；真实零用量不改变结果，明确返回的缓存读取0属于有效明细。全部缺失时显示“未提供”。周期总词元与总费用仍展示完整周期，不能借用一个周期的明细分摊到另一个周期。

## 无障碍与平台要求

可操作区域至少48dp，文字使用可缩放字号，布局不固定文本区域高度。标题、导航、筛选项、图表和详情提供辅助功能语义。支持浅色、深色、200%字体、横屏和可调整大小的窗口。登录页继续保护系统截图与任务预览；访问密钥按既有系统密钥库机制保存。

安卓17的局域网权限仅在连接内网服务器时申请。联网入口统一处理首次连接、已保存会话恢复和并发请求，拒绝时给出可读说明。公网连接维持原有加密要求。

## 验证

构建流程包含安装包编译、静态检查、数据单元测试，以及安卓14和17设备测试。设备测试覆盖五个入口、模型搜索、设备与会话筛选、趋势范围和词元／费用切换、逐日选择与详情、重建和旋转后的状态恢复、深色和大字体，并保存模拟器截图供审阅。最终安装包检查64位架构与16KB内存页打包对齐。

平台规范依据：[安卓17行为变化](https://developer.android.com/about/versions/17/behavior-changes-17)、[安卓构建插件9.4](https://developer.android.com/build/releases/agp-9-4-0-release-notes)、[触摸区域与辅助功能](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)、[预测性返回手势](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)。
