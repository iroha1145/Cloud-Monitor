# v0.2.0 · 全新用量工作台

这次更新带来新版网页面板、完整的手机适配，以及更准确的每日缓存统计。已配置在线更新的部署，可在面板检查并更新到 **v0.2.0**，完成后刷新页面。

## 主要变化

- **新版用量面板**：统一总览、模型、设备、配额与订阅、历史记录的页面布局，完善深色模式、图标、图表和明细查看。
- **手机浏览与操作**：加入底部导航，调整模型指标、矩阵和活动图的布局；修复手机菜单错位，完善横竖屏切换、滚动和触屏操作。
- **每日趋势与缓存占比**：展示当天用量、花费和缓存明细。区间比例只统计有有效缓存数据的日期，并标明参与天数；缺失日会跳过，未使用的日期不影响结果，已确认的零缓存正常计入。
- **缺失数据保持真实**：不再把缺失缓存当作零，也不拿当前周期的数据推算历史。部分已识别数据保留相应说明，刷新失败时保留已加载内容。
- **同步与恢复修复**：改善限流重试、桥接网络异常处理，以及备份恢复后的文件权限和启动验证。

## 安卓客户端

本次发布同时收录自 v0.1.4 以来新增的安卓（Android）原生客户端，包含概览、设备、配额、历史和内置演示数据。支持 Android 9 及以上的 64 位设备。

安装包由单独的构建流程提供，详见[安卓客户端构建与安装说明](https://github.com/iroha1145/Cloud-Monitor/blob/v0.2.0/docs/android/README.md)。

## 升级说明

- 通过安装脚本部署并启用更新监视器的服务，可在面板中执行在线更新；仅手动启动容器的部署，请参照[在线更新说明](https://github.com/iroha1145/Cloud-Monitor/blob/v0.2.0/README.md#在线更新)配置。
- 容器构建会自动编译新版面板。直接运行后端源码时，需要先在 `hub/dashboard` 执行 `npm ci && npm run build`；本次构建使用 Node.js 24。
- 启动时会自动补充缓存明细标记字段。旧日记录缺失的明细不会被补造，区间缓存计算会忽略这些日期。
