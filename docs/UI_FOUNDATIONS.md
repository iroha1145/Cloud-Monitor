# 全站排版与阅读规范

2026-10-23 对照 [TypeUI UI Foundations](https://www.typeui.sh/ui-foundations/configurator?category=text&example=type-scale) 阅读全部公开目录：24 类、118 个示例，并检查行高、行宽、分组、留白和点击区等滑杆的对照状态。付费下载内容不在本次可读取范围。

这些示例用于判断信息是否易读，不是把每个示例中的装饰或固定尺寸搬进工作台。保留现有白底、配色、移动导航、模型行直角和数据语义。未知数据继续显示“未提供”。

## 统一的文字角色

所有页面、登录页以及通过门户渲染的菜单和弹窗共用 `src/tokens.css`。

| 角色 | 默认字号 | 用途 |
| --- | --- | --- |
| 页面标题 | 28，手机 24 | 页面名称 |
| 弹窗标题 | 24 | 模型名、设置、通知 |
| 章节标题 | 18，字重 600 | 用量组成、相关会话、更新说明 |
| 正文 | 16 | 字段值、说明段落、会话名称 |
| 辅助文字 | 14 | 标签、时间、单位、备注 |
| 数据 | 20 / 28 / 36 | 行内数据、摘要、主要指标 |

字号使用相对单位；正文不随屏幕缩小。标题行高 1.25，正文 1.6，辅助文字 1.5。数值使用等宽数字，数值与单位按基线对齐。长说明限制在约 65 个拉丁字符宽度内；名称和标识允许换行。

间距采用 4、8、12、16、24、32 的层级。组内距离小于组间距离，卡片内边距通常 16 或 24；避免给紧凑卡片添加大片留白。主要操作与相邻控件保持共同高度；手机点击区至少 44 像素。

## 页面与弹窗覆盖

- 总览与模型分析：摘要、图表、图例、模型表、客户端、项目用量、筛选及空状态。
- 设备、配额与订阅、历史记录：所有列表、展开内容、活动日历、日期筛选和每日归档。
- 弹窗：模型详情及其测速、会话、来源与模型；快速查找；连接与设置；通知；设计说明。
- 托管入口：登录、连接失败、服务版本、发布说明、更新任务和错误。
- 公共界面：导航、外观菜单、指标提示、加载失败、页脚和通知。

模型详情采用固定标题与独立滚动正文。宽屏将用量图与明细并排；窄容器改为纵向。会话数字和事实字段根据实际可用宽度调整列数，历史行内详情复用相同规则。

## 验证

`tests/typeui-foundations.spec.ts` 检查五个页面在 320、390、768、1440 像素的可读层级和页面宽度、详情独立滚动、44 像素关闭入口、文字放大两倍、深色模式和懒加载样式的一致性。原有浏览器测试继续覆盖长名称、未知字段、交互、过滤和导出；托管测试覆盖真实后端接收、持久化、刷新后的显示、登录与更新。
